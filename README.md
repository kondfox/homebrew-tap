# kondfox/homebrew-tap

Homebrew formulae for kondfox tools.

```sh
brew install kondfox/tap/pmx
```

| Formula | What it is |
|---|---|
| `pmx` | Engineering metrics from git history, with a web dashboard: [kondfox/project-metrics](https://github.com/kondfox/project-metrics) |

The formulae in `Formula/` are written by each project's release workflow; don't edit them by hand.
